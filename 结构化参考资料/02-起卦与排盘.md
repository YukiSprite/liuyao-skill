# 起卦与排盘

来源：[原始排盘转录稿](<../六爻零基础 I 增删喂饭级教程，用力讲大白话——建议收藏 (1).txt>)；[视频第 2 集](https://www.bilibili.com/video/BV12bzpBuEuG/?p=2)。

本篇整理教程中的排盘方法。第三份转录稿第 5 行提到此前课件存在卦画错误，因此本文区分文字可恢复的规则与需要补图核验的内容。没有将缺失画面补成完整卦盘。

## 1. 排盘流程概览

**整理归纳，来源：S2，第 7—35 行。**

1. 明确硬币正反面及记录约定。
2. 记录起卦年月日时，查询干支，确定所用旬空。
3. 三枚硬币连续投掷六次，按先后顺序自下而上记录。
4. 转换为六条爻，标明老阴、老阳，得到本卦和变卦。
5. 分辨内外卦，确定本卦的世应与所属卦宫。
6. 纳甲：为各爻配上对应干支。
7. 按本卦卦宫五行确定六亲。
8. 本卦缺少六亲时，按本教程方法从本宫卦取出相应伏神。
9. 按日干自初爻起排六神。

## 2. 投币工具与约定

来源：S2，第 5、7、9、11 行。

### 2.1 工具

讲者认为三个相同、具有可区分两面的物件即可作为摇卦工具，可以是硬币、古钱币或游戏币；其讲解不以钱币真假、国别作为使用条件。

### 2.2 正反面约定

讲者列举了不同的阴阳面判定说法，并主张选定后保持一致。转录中的“这面”“那面”依赖视频画面，不能从文字确定每一种钱币的具体哪一面。

本篇采用讲者随后明确给出的**背面数量映射**整理。例题中讲者又用“花”计数；这一称呼仅按该例的上下文与背面计数对应，不据此断定所有硬币的花面都等于背面。

**整理提示：** 后续接收用户的“正、反、字、花”结果时，需要先知道其实际约定，才能套用下表。

## 3. 时间与旬空

来源：S2，第 7 行。

讲者要求先用万年历查询起卦时的年月日时干支，再查相应旬空。

### 3.1 原稿时间示例

| 字段 | 转录稿给出的值 |
|---|---|
| 公历时间 | 2021 年 10 月 13 日 09:14 |
| 年柱 | 辛丑 |
| 月柱 | 戊戌 |
| 日柱 | 甲午 |
| 时柱 | 己巳 |
| 该例日旬空 | 辰、巳 |

以上为原稿示例记录，未通过历法工具独立核验。原稿没有提供时区、节气换月或换日边界约定。

### 3.2 可整理出的查空思路

- 讲者以“找旬首”为查空步骤，指出旬首以甲开头。
- 甲午日恰为旬首，例中以午之前的辰、巳说明旬空。
- 讲者另以其他术数查时旬空作对比，强调应先确定所查的干支对象。

**本节未展开：** 非旬首日如何求所属旬、完整六十甲子表和通用算法。原稿声称基础视频讲过相关内容，但当前 S1 文件未包含这部分，不能视为资料已经齐全。

## 4. 六次投币、爻序和内外卦

来源：S2，第 7、9 行。

### 4.1 记录顺序

| 投掷次序 | 爻位 | 所属部分 |
|---|---|---|
| 第 1 次 | 初爻，最下方 | 内卦 |
| 第 2 次 | 二爻 | 内卦 |
| 第 3 次 | 三爻 | 内卦 |
| 第 4 次 | 四爻 | 外卦 |
| 第 5 次 | 五爻 | 外卦 |
| 第 6 次 | 上爻，最上方 | 外卦 |

下面三爻组成内卦，上面三爻组成外卦。记录顺序是从下往上，阅读完整卦图时则要留意其最上方对应第六次投掷。

### 4.2 背面数量与爻的对应

来源：S2，第 9、11 行；变后阴阳由第 11、13 行规则展开。

| 一次投掷中的背面数 | 名称 | 本卦阴阳 | 动静 | 变后阴阳 |
|---|---|---|---|---|
| 0 | 老阴 | 阴 | 动 | 阳 |
| 1 | 少阳 | 阳 | 静 | 阳，不变 |
| 2 | 少阴 | 阴 | 静 | 阴，不变 |
| 3 | 老阳 | 阳 | 动 | 阴 |

老阴、老阳必须有可辨认的标记。讲者认为标记的具体形状不是关键，关键是能够准确识别哪些爻发生变化。本文直接使用“老阴”“老阳”文字，避免圈叉符号约定不一致。

## 5. 本卦、变卦与静卦

来源：S2，第 11、13 行。

- **本卦：** 六次投币直接形成的六爻组合。
- **动爻：** 本卦中的老阴或老阳。
- **变卦：** 将动爻阴阳翻转、其他爻保持原状后形成的组合。
- **静卦：** 六爻中没有老阴或老阳。本教程称其只有本卦，不另列变卦。

多爻发动时，各动爻都按阴变阳、阳变阴处理。

## 6. 八宫与本宫卦

来源：S2，第 13、15 行。

### 6.1 八个本宫卦

| 内外卦相同的组合 | 名称 |
|---|---|
| 乾上乾下 | 乾为天 |
| 坎上坎下 | 坎为水 |
| 艮上艮下 | 艮为山 |
| 震上震下 | 震为雷 |
| 巽上巽下 | 巽为风 |
| 离上离下 | 离为火 |
| 坤上坤下 | 坤为地 |
| 兑上兑下 | 兑为泽 |

讲者以每个本宫卦派生七卦，连同本宫卦共八卦，说明八宫合计六十四卦。

**整理用语：** 本篇用“本宫卦”指内外相同的具体六爻卦，用“所属卦宫”指某卦的归属。原稿中二者有时混称为“卦宫”。

### 6.2 宫内演变顺序

本宫卦 → 一世卦 → 二世卦 → 三世卦 → 四世卦 → 五世卦 → 游魂卦 → 归魂卦。

讲者以乾为天为例，从初爻开始逐次向上翻转，到五爻后不继续翻转上爻，而转入游魂、归魂的讲解。

**待核验：** 游魂步骤具体指向及后续“三爻全变”的画面没有保存在转录中。这里保留顺序和能够辨认的描述，不把它扩写为已经核验的逐步生成算法。完整六十四卦名称、卦画及宫属表也未出现在当前文字资料中。

## 7. 寻世应

来源：S2，第 17、19 行。

### 7.1 比较内外卦对应爻

讲者把内外卦分别分成天、人、地三位。

**整理展开：** 内外卦的对应比较位置为：

| 比较位 | 内卦位置 | 外卦位置 |
|---|---|---|
| 天 | 三爻 | 上爻 |
| 人 | 二爻 | 五爻 |
| 地 | 初爻 | 四爻 |

“同”表示对应两爻阴阳相同，“异”表示阴阳不同。下列“只有”条件不能省略。

### 7.2 世爻位置

| 内外卦比较结果 | 世爻位置 | 原讲解分类 |
|---|---|---|
| 只有天位相同 | 二爻 | 二世 |
| 只有天位不同 | 五爻 | 五世 |
| 只有地位相同 | 四爻 | 四世 |
| 只有地位不同 | 初爻 | 一世 |
| 只有人位相同 | 四爻 | 游魂 |
| 只有人位不同 | 三爻 | 归魂 |
| 天、人、地全部相同 | 上爻 | 本宫卦 |
| 天、人、地全部不同 | 三爻 | 三世 |

原稿口诀按后续释义整理为：

> 天同二世天异五，地同四世地异初；人同游魂人变归，本宫六世三世异。游魂于四，归于三。

以上为依据转录释义恢复的口诀文字，未核对视频字幕或古籍原文。第 17 行关于游魂位置有短暂混说，表格采用同段反复明确的“四爻”，详见 Q03。

### 7.3 应爻位置

讲者说明世爻与应爻之间隔两爻。**整理推演：** 对应关系为初爻 ↔ 四爻、二爻 ↔ 五爻、三爻 ↔ 上爻。

## 8. 寻本卦所属卦宫

来源：S2，第 21、23 行。

按讲者解释，将特殊情况先列出，避免口诀被错误套用：

| 情形 | 本教程的寻宫方法 |
|---|---|
| 内外卦相同，为本宫卦 | 直接确定所属宫，不再翻转另寻 |
| 归魂卦 | 以内卦确定所属宫 |
| 其他卦，世爻在内卦 | 以外卦确定所属宫 |
| 其他卦，世爻在外卦 | 将内卦三爻阴阳全变，再据所得三爻卦确定所属宫 |

这里查找的是**本卦的所属宫**。

讲者还在区分三世卦与归魂卦的语境下提出：翻转五爻后若内外相同，可据此识别归魂；否则为三世。该辅助说明只保留在其原有比较范围内，不扩大成适用于任意卦的分类规则。

## 9. 纳甲

来源：S2，第 23—29 行。

### 9.1 基本操作

1. 先分辨当前三爻卦是内卦还是外卦。
2. 查相应起始干支：内卦从初爻起，外卦从四爻起。
3. 依据该三爻卦的阴阳属性，按地支顺序隔位顺排或逆排。
4. 各组内部从下往上填写。

| 三爻卦分组 | 排地支方向 |
|---|---|
| 乾、坎、艮、震为阳 | 隔位顺行 |
| 巽、离、坤、兑为阴 | 隔位逆行 |

**整理解释：** “隔位”是在十二地支序列中每次跳过一个地支，不是逐支连续填写。

### 9.4 天干变例：只记录为待核事项

本文不擅自恢复其正式术语、书名或使用条件，也不将其设为默认排盘规则。详见 Q05。

## 10. 排六亲

来源：S2，第 29—31 行。

### 10.1 参照对象

按**本卦所属宫的五行**作为“我”，比较每爻地支的五行：同我为兄弟，生我为父母，我克为妻财，克我为官鬼，我生为子孙。

本教程明确要求：为变卦标六亲时，仍沿用本卦所属宫的五行作为参照，不重新改用变卦所属宫的五行。

### 10.2 原稿给出的卦宫示例

| 卦宫 | 原稿所用五行 | 例示 |
|---|---|---|
| 艮宫 | 土 | 火为父母、木为官鬼、土为兄弟 |
| 乾宫 | 金 | 土为父母、火为官鬼、木为妻财、金为兄弟 |
| 坎宫 | 水 | 火为妻财、木为子孙、土为官鬼、金为父母、水为兄弟 |

完整八宫五行表不在本稿的明确列举中，本文不据此宣称已收齐。

## 11. 补伏神

来源：S2，第 31、33 行。

讲者描述了“本卦缺六亲时，从本宫卦对应爻位补出”的方法；本篇以“伏神”作为这一操作的主题标题。

1. 先检查本卦的六亲是否缺项；本教程在此步骤不以变卦的六亲补足判定。
2. 排出本卦所属宫的本宫卦及其纳甲、六亲。
3. 在本宫卦中找到所缺六亲。
4. 将其标在当前卦的对应爻位。

### 11.1 原稿示例与疑点

讲者以一个艮宫卦缺子孙、妻财为例，说从艮为山中找到第三爻子孙申金、第五爻妻财子水，再标回对应爻位。

原稿将第三爻写为“丙申”、第五爻写为“丙子”。**整理推演：** 按同稿“艮内丙辰起、艮外丙戌起、阳卦隔位顺行”展开，内卦依次为丙辰、丙午、丙申，外卦依次为丙戌、丙子、丙寅；这两个爻位与文字规则一致。此为内部对照，尚未回看原视频图示。

原例完整本卦、动爻和图中标注未提供，故本例仅用于说明补位过程，不能作为完整排盘测试案例。

## 12. 排六神

来源：S2，第 33、35 行。

### 12.1 固定循环顺序

青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武 → 青龙。

讲者用“龙、雀、勾、蛇、虎、玄”帮助记忆。

### 12.2 由日干确定初爻

| 日干 | 初爻起六神 |
|---|---|
| 甲、乙 | 青龙 |
| 丙、丁 | 朱雀 |
| 戊 | 勾陈 |
| 己 | 螣蛇 |
| 庚、辛 | 白虎 |
| 壬、癸 | 玄武 |

确定初爻后，按固定循环顺序向上填写剩余五爻。

**整理推演示例：** 己日由初爻到上爻依次为螣蛇、白虎、玄武、青龙、朱雀、勾陈。

### 12.3 与五行的讲解联系

讲者将青龙对应木、朱雀对应火、勾陈对应土、白虎对应金、玄武对应水，并把螣蛇表述为“火土两性”，借此解释记忆顺序。

该段是讲者的属性说明；排六神实际采用的是日干起首与固定顺序，不需要先用上述属性重新推导排列。

**校对说明：** 原稿第 35 行先出现“己日……玄武”，随后又明确改为“己日……腾蛇”。本篇采用第 33 行口诀及第 35 行末尾一致的“己起螣蛇”，保留冲突记录于 Q04。
