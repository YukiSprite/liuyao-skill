# 术语校对、疑点与缺失资料

本清单记录三份转录稿中的术语识别问题、内部矛盾和缺失信息。当前仅完成文字内部对照；“已整理”不等于已经回看视频或核验古籍。来源编号和原始文件见 [资料目录](00-资料目录与整理说明.md)。

## 1. 术语归一表

以下按上下文逐处处理，不作不分语境的全文替换。尤其“巳、午、未”“戊、己”“辰、戌”等字直接影响排盘，不能只凭字形或同音批量替换。

| 转录中的常见写法 | 正文统一用语 | 使用依据或限制 |
|---|---|---|
| 排挂、排卦 | 排卦／排盘 | 排列卦象的语境 |
| 爻卦 | 摇卦 | 指投掷硬币时；“爻”作为名词时保留 |
| 出爻、出妖、屠妖 | 初爻 | 明确指最下方第一爻时 |
| 外挂、内挂 | 外卦、内卦 | 三爻组合的语境 |
| 挂宫、卦功、挂钩、化工 | 卦宫 | 明确讨论卦的宫属时 |
| 适应、事应 | 世应 | 寻世爻、应爻的语境 |
| 视爻、事爻、世腰 | 世爻 | 由上下文确认所指 |
| 纳钾、钠钾 | 纳甲 | 给爻配干支时 |
| 奇财、奇才、其财、七财 | 妻财 | 六亲名称的语境 |
| 凤爻、父美爻等 | 父母爻 | 指父母六亲且上下文清楚时 |
| 自尊 | 子孙 | 六亲名称的语境 |
| 老杨、烙印 | 老阳、老阴 | 投币四种结果的语境 |
| 月见、月进、月经 | 月建 | 讨论月令作用时 |
| 修球、修求 | 休囚 | 讨论旺衰时 |
| 空旺、空网、空王 | 空亡 | 讨论旬空时；具体历法对象另辨 |
| 巡手、旬手 | 旬首 | 六十甲子分旬的语境 |
| 祭神、纪神 | 忌神 | 克用神者的语境 |
| 原神、源神、渊神 | 元神 | 生用神者的语境 |
| 纪元同洞、忌元同洞 | 忌元同动 | 忌神、元神共同发动的语境 |
| 钩辰、钩沉 | 勾陈 | 六神名称 |
| 腾蛇、舌 | 螣蛇 | 六神名称，统一采用“螣蛇”写法 |
| 虎旋、互旋 | 虎、玄／白虎、玄武 | 六神顺序语境 |
| 辅音、反应 | 伏吟、反吟 | S3 第 15 行疑似术语，仅作为待补概念，不补写定义 |

有些条目代表压缩后的多个识别变体。涉及实质规则的校正不只依靠这张表，还需看下面逐项记录。

## 2. 实质疑点登记

### Q01 亥水可以克子水

- **位置：** S1，第 13 行。
- **原文：** “戌土可以克亥子，亥水可以克子水”。
- **问题：** 同稿将亥、子均归水，五行生克表没有水克水关系。后半句与自身规则冲突。
- **本次处理：** 正文保留“戌土克亥子水”，将“亥水克子水”排除出有效示例。
- **待做：** 回看原音，判断是转写误接、口误还是漏词；目前不猜改成另一组具体地支。

### Q02 同性为冲，异性为克

- **位置：** S3，第 7、9 行。
- **原文：** “同性为冲，异性为克”。
- **问题：** 口头概括比同段列出的六冲配对范围更宽；若据此生成所有同阴阳配对，会产生与配对表不一致的结果。
- **本次处理：** 03 中保存此说法的原始例子语境，另保留六组具体冲对；不把概括当成通用公式。
- **待做：** 核对视频表述及适用范围，区分解释比喻与严格定义。

### Q03 游魂世爻在三爻还是四爻

- **位置：** S2，第 17 行。
- **原文片段：** “游魂的世爻在第三爻，第四爻归魂的世爻在第三爻”。
- **内部对照：** 同段多次明确“游魂世爻在第四爻”，并给出“游魂于四，归于三”的解释。
- **本次处理：** 02 的表格采用游魂世在四爻、归魂世在三爻。
- **状态：** 已按上下文整理，尚未核对音视频。

### Q04 己日起玄武还是螣蛇

- **位置：** S2，第 33、35 行。
- **冲突：** 第 35 行先出现“己日，初爻就是玄武”，随后又说“己日，初爻就是腾蛇”。
- **内部对照：** 第 33 行的完整口诀也将己日起首指向螣蛇，壬癸日起首指向玄武。
- **本次处理：** 02 采用“己日起螣蛇；壬癸日起玄武”。
- **状态：** 已按前后明确一致的表述整理，尚未核对音视频。

### Q05 冬至夏至相关天干变例

- **位置：** S2，第 27、29 行。
- **原转写：** “二老时迁”“二到时迁”“二老师谦”；书名为“伊尹”。
- **可辨认内容：** 讲者提到冬至、夏至与甲壬等天干互换，并称地支不变。
- **问题：** 正式术语、书名、乾坤各自如何变、何时采用，均不能仅凭现有转写准确恢复。
- **本次处理：** 02 记录为待核变例，不纳入默认排盘流程。
- **待做：** 回看对应画面和音轨，记录准确术语、书名、规则与适用条件。

### Q06 纳甲起始表残缺或识别不清

- **位置：** S2，第 25、27 行。
- **乾：** “乾内甲子外人物”中的外卦起始疑为壬午，但未确认。
- **离：** “离内即貌，外机有”等疑为己卯、己酉，但未确认。
- **震：** 现有文字没有完整给出内外起始。
- **坤：** 现有文字明确给出内卦乙未，外卦起始缺失。
- **本次处理：** 02 的起始表保留“疑为”“未提供”，没有从模型记忆补成完整标准表。
- **待做：** 获取完整口诀或清晰表格，并与每一组三爻排列交叉核对。

### Q07 仇神的定义短句冲突

- **位置：** S3，第 17、19 行。
- **原文：** “克制克制忌神道就是仇神”。
- **内部对照：** 前后用金为用神、土为元神、火为忌神，明确指出“克土生火者木”为仇神。
- **本次处理：** 03 依据清楚的关系示例整理为“克元神并生忌神者”，不采用冲突短句。
- **状态：** 已按内部示例整理，原句准确音轨待核。

### Q08 旬空教程的引用与实际资料不符

- **位置：** S2，第 7 行；与完整 S1 对照。
- **问题：** 讲者称前一个基础视频讲过六十甲子和查空，但当前 S1 只有阴阳五行、干支与六亲，没有完整六十甲子或旬空算法。
- **本次处理：** 02 保留甲午日辰巳空的原稿示例，标记算法资料缺失。
- **待做：** 确认是否另有基础视频、漏转片段或不同版本；补齐来源后再建立算法。
- **附带事项：** 原例公历与干支对应尚未核验，时区和换日约定也未说明。

### Q09 纷争案例的世爻与日月称谓混说

- **位置：** S3，第 25、27、29 行；对应 03 的 C02。
- **冲突数据：** 原稿主要说明世爻子水、应爻午火、另一动爻戌土，但第 25 行夹有“世爻呢戌土”；第 27 行夹有“临了月见”。
- **内部对照：** 第 27、29 行反复用“世爻子水与日辰相比”“世爻临了日辰”解释。
- **本次处理：** C02 数据表采用反复一致的“世爻子水、日支子、月支寅”，不采用冲突短句。
- **应期疑点：** 末尾“元神被寅木克制”所指不清，不能凭该句恢复寅日应期的完整理由。
- **待做：** 补完整卦盘和原案日期，核对人物取象与应期解释。

### Q10 贸易案例的空亡与完整性

- **位置：** S3，第 21、23、25 行；对应 C01。
- **原转写：** “巳月甲寅日啊，自抽空”。
- **本次处理：** “自抽空”标为疑似“子丑空”，未当作确认数据。
- **额外问题：** 讲者明确说该卦另有问题而不深究；原文未提供完整卦名、六爻位置和变爻。
- **待做：** 获取原卦及讲者所说问题的上下文。在此之前，案例仅用于区分仇神与仇人。

### Q11 父病案例的多现用神与规则条件

- **位置：** S3，第 29—35 行；对应 C03。
- **数据问题：** 讲者数出辰、戌、未三处父母，但没有画面，不能确认这些候选是否全在本卦，还是含变爻。
- **规则问题：** “取旺者”“日冲暗动”“忌元同动”“化合待冲”等在这里以个案形式出现，尚无完整适用条件。
- **本次处理：** 03 分别记录案例数据、讲者分析、应期和反馈；不从单例推出通用结论。
- **待做：** 补本变卦、爻位、日干及相关专章。“辰月”目前仅由“辰土临月建”推得，须与原案确认。

### Q12 卦图与课堂数据的缺失

- **位置：** S2 多处“这个卦”“这儿”；S3 第 5 行的课件自述。
- **问题：** 讲者承认部分 PPT 卦画曾与卦名不一致；纯文本又不能保留其指向位置。
- **本次处理：** 只展示由明确输入可直接推演的 110213 阴阳爻象，没有填入来源不明的完整案例卦盘。
- **待做：** 获取原图后，逐项核对卦名、上下卦、动爻、世应、纳甲、六亲，不把整张课件图自动当作正确答案。

### Q13 四处生克的计数口误

- **位置：** S3，第 21 行。
- **原转写：** “三处相克，一处相生”之后又出现“四个地方都来克你，只有一个地方来生你”。
- **问题：** 同一段的作用数量自相矛盾。
- **本次处理：** 03 按段首及后续旺衰说明整理为“三克一生”，保留计数冲突提示。
- **边界：** 四处分类是讲解框架，不能强行为未发动的用神补出一个本位变爻。

## 3. 缺失内容与补充优先级

以下是整理者根据资料缺口列出的补充清单，不冒充讲者已讲授内容。

| 优先级 | 待补内容 | 当前缺口 | 对后续使用的影响 |
|---|---|---|---|
| 高 | 硬币正反面与“花／背”对应 | 部分依赖画面 | 用户投币结果可能被反向解释 |
| 高 | 八卦卦画、八宫五行、完整卦名与宫属表 | 当前文字未完整列出 | 不能建立全量排盘数据 |
| 高 | 完整内外纳甲表 | 有缺项和疑似错字 | 六亲、伏神及作用分析的基础可能出错 |
| 高 | 历法、六十甲子和旬空 | 有例题，无完整规则与边界约定 | 时间转换和旬空无法可靠自动化 |
| 高 | 原始案例卦图 | 三个案例均不完整 | 不能作为端到端排盘验证样例 |
| 高 | 旺衰及元忌有力、无力条件 | 多次留待后续 | 无法判断名义生克是否真正起作用 |
| 中 | 暗动及其他日冲状态 | 仅有个案 | 容易将日冲一律当作暗动 |
| 中 | 空亡、月破及其条件 | 仅引入概念 | 不能判断是否有用、何时恢复作用 |
| 中 | 合、化合、合绊和冲开 | 案例说明代替完整定义 | 容易把所有合都当作阻碍 |
| 中 | 用神多现、伏藏及复杂问事取用 | 基础取用加单个案例 | 可能选错所分析对象 |
| 中 | 应期判断 | 只有个案日期与局部说明 | 不足以自动推断具体发生日期 |
| 后续 | 伏吟、反吟等被点名概念 | 本稿未展开 | 不能从术语识别直接生成判断规则 |
| 后续 | 冬至夏至相关天干变例 | 术语、版本和条件不清 | 不宜混入第一版默认排盘 |
