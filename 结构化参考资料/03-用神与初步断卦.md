# 用神与初步断卦

来源：原始用神转录稿（仅本地保留）；[视频第 3 集](https://www.bilibili.com/video/BV12bzpBuEuG/?p=3)。

本篇整理讲者引入《增删卜易》时的概念和案例。涉及的书中章节、断语和反馈均为讲者转述，未与古籍底本或视频画面独立核对。正文不是经验证的预测方法说明。

## 1. 本节与前两份资料的关系

来源：S3，第 5 行。

讲者将前面的起卦课程对应到其所讲版本《增删卜易》的第一至第七章，将基础课程中的六亲部分与第八章用神内容联系起来，然后进入用神、元神、忌神和仇神的讨论。

讲者同时承认此前 PPT 中存在卦名与卦画不一致、复制后忘改卦画等问题。这会影响将课件案例直接作为排盘标准答案的可靠性。

## 2. 地支六合与六冲

来源：S3，第 5、7、9 行。

### 2.1 六合配对

子丑合、寅亥合、卯戌合、辰酉合、午未合、巳申合。

讲者以拥抱、拉手、关系亲近等解释“合”的象；在另一些情境下，“合”也可能表现为被拉住、行动受阻。因此不能只看到“合”就判断有利。

### 2.2 六冲配对

子午冲、卯酉冲、寅申冲、巳亥冲、辰戌冲、丑未冲。

讲者以冲突、碰撞、打碎等解释“冲”的象，同时强调“冲”本身不直接等于不利。

### 2.3 “同性为冲，异性为克”的适用疑点

原稿在解释子午、巳亥、子巳的例子时，出现“同性为冲，异性为克”的概括。

**待核验与整理限制：** 这句话不能据字面扩写为“任何两个同阴阳地支都相冲”。例如寅与午都在 S1 的阳支表中，但不是本节列出的六冲配对。本文将具体配对表与这一口头概括分开保存，后续判断配对不能用该概括替代表格。

本节列举的是地支配对；哪些六爻卦属于“六冲卦”或“六合卦”，当前资料没有完整列出。

## 3. 问事、取用与基本时间概念

来源：S3，第 9、11、15、17 行。

### 3.1 分析前的记录

先写明所问之事、起卦年月日时、卦象及六神等信息，再进入取用和生克分析。

### 3.2 用神的基本取法

用神是卦中被选来代表所问对象或事项的爻。

| 本节讨论的情境 | 讲者给出的取法 |
|---|---|
| 自占自身吉凶 | 以世爻为用神 |
| 问父母 | 以父母爻为用神 |
| 问兄弟 | 以兄弟爻为用神 |
| 问妻子 | 以妻财爻为用神 |
| 问财 | 以妻财爻为用神 |

**整理提示：** 讲者在“自占自身吉凶”语境中使用世爻，随后也明确讲到问财另取财爻。不能把“用户问自己的问题”一概改写成“全部以世爻为用神”。本稿还没有给出覆盖所有问题类型的取用表。

### 3.3 时间术语

来源：S3，第 11 行。

| 术语 | 本节说明 | 原稿说明性例子 |
|---|---|---|
| 太岁 | 年所对应的概念 | 庚辰年 |
| 月建／月令 | 月的地支 | 癸未月中的未 |
| 日辰 | 日的地支 | 辛卯日中的卯 |
| 时辰 | 时的地支 | 甲午时中的午 |

这些是讲解术语时使用的示例，不据此拼成一个已核验的实际起卦时间。

### 3.4 旺衰的初步含义

以世爻戌土为例，讲者说自占时希望用神旺相、受到生扶，不希望其休囚、受克、落空或临月破。

“旺相”“休囚”“空亡”“月破”的完整判定条件在本节没有讲完；本篇保留其概念角色，不补造算法。

## 4. 四处作用与作用范围

来源：S3，第 11—17 行。

### 4.1 四处作用来源

讲者以用神为分析中心，讨论月建、日辰、卦中动爻、该爻发动后化出的变爻四处作用。

| 作用来源 | 本节描述的作用对象 | 举例或限制 |
|---|---|---|
| 月建 | 卦中各爻；后文包括变爻 | 巳月火生戌土，卯月木克戌土 |
| 日辰 | 卦中各爻；后文包括变爻 | 巳午火日生戌土，卯木日克戌土 |
| 本卦动爻 | 本卦的静爻、动爻 | 未土动可生酉金或克亥水 |
| 本位动爻化出的变爻 | 对应的本位动爻 | 讲者限定为回头作用，不能任意作用其他爻 |

**条件边界：** “有作用关系”不等于“在所有条件下都能有效作用”。旺衰和作用受阻问题见后文；暗动成立条件也尚未完整提供。

### 4.2 回头生与回头克

- 申金发动化出土，讲者以土生金说明“回头生”。
- 子水发动化出丑土，讲者以土克水说明“回头克”，同时承认该例还涉及合的关系，但没有给出此处生克、冲合的完整优先顺序。

这里的“回头”强调作用回到化出该变爻的本位动爻。若用神没有发动，不能为了凑齐“四处”而替它虚构一个本位变爻。

### 4.3 静爻与暗动

讲者以“静爻没有腿”比喻其不能像动爻一样主动作用，后面的案例又引入暗动，称暗动的爻可按动爻参与分析。

**整理限制：** 这只是入门讲解的概念层次，不能从比喻推出“所有静爻永远无作用”，也不能从个案推出“所有受日冲的静爻都暗动”。

## 5. 用神、元神、忌神、仇神

来源：S3，第 17、19 行。

| 名称 | 本节定义 | 以金为用神的例子 |
|---|---|---|
| 用神 | 代表所问事项或对象、先行选定的爻 | 金 |
| 元神 | 生用神者 | 土生金，所以土为元神 |
| 忌神 | 克用神者 | 火克金，所以火为忌神 |
| 仇神 | 克元神、并生忌神者 | 木克土且木生火，所以木为仇神 |

关系示意：

```text
土（元神） ──生──→ 金（用神）
火（忌神） ──克──→ 金（用神）
木（仇神） ──克──→ 土（元神）
木（仇神） ──生──→ 火（忌神）
```

讲者用“帮助者给我支持，另一个人阻止帮助者”的比喻说明仇神可能间接影响用神。

**校对说明：** 第 19 行出现“克制克制忌神……就是仇神”的混乱语句；正文依照紧接着明确给出的“克土生火者木”及前文示例整理，没有采用冲突短句。

**名词边界：** 仇神是关系名称，不直接等同于现实中的仇人。案例 C01 专门讨论这一点。

## 6. 生克数量与旺衰

来源：S3，第 19、21 行。

### 6.1 本节的概括性判断

以下是讲者对“四处作用”的入门概括，不是经过独立核验的通用评分表。

| 所述情形 | 讲者给出的概括 |
|---|---|
| 四处都生合用神 | 作吉论 |
| 三处生、一处克 | 仍作吉论 |
| 两处生、两处克 | 进一步看旺衰 |
| 三处克、一处生 | 要看生扶者是否旺相、有力 |
| 四处都克 | 作大凶论 |

原文在“三处克、一处生”的段落夹有“四处都来克、只有一处来生”的重复冲突措辞；此表按该段开头与后续解释归纳，未照抄矛盾计数。

### 6.2 有生克之名，不一定有实际作用

讲者的重点是作用者是否有力量：

- 生用神者旺相，讲者认为其生扶作用更有力。
- 克用神者旺相，讲者认为其克害作用更有力。
- 生扶者休囚无力，可能只是“有生之名，无生之实”。
- 三处克而一处生时，有力的生扶者仍可能改变其综合判断。

**整理提示：** 本节本身已经要求看旺衰和能否作用，因此不应把上表改成简单加减分，更不能据此输出百分比概率。

## 7. 案例 C01：往营中贸易

来源：S3，第 21、23、25 行。案例标题为整理命名。

### 7.1 文字中可辨认的数据

| 字段 | 转录信息 |
|---|---|
| 所问事项 | 是否前往营中贸易 |
| 月、日 | 巳月、甲寅日 |
| 旬空 | 原转写“自抽空”，疑为“子丑空”，待核验 |
| 世爻 | 卯木 |
| 应爻 | 酉金，发动 |
| 元神关系 | 水生卯木，讲者举亥水 |
| 仇神关系 | 讲者指出妻财丑土为仇神 |
| 本卦、变卦名称 | 文字未明确提供 |
| 六爻完整位置和变爻 | 缺失 |

### 7.2 讲者的分析

1. 世爻代表自己，应爻代表对方。
2. 应爻酉金发动克世爻卯木，所以酉金相对世爻为忌神。
3. 讲者转述的断语为不宜前往，可能有仇人为害。
4. 这里现实中的“仇人”取自对方克害自己的关系，不要求该人对应术语“仇神”。

### 7.3 转录中的结果与教学重点

讲者称事后被仇人陷害。此为转述反馈，未独立验证。

本例用于区分“仇神”与“仇人”；讲者随后还说该卦另有问题，不作细究。因此本例目前仅适合作为术语辨析材料，不宜作为完整断卦的标准答案。

## 8. 案例 C02：遭人诈害，求解纷争

来源：S3，第 25—29 行。案例标题为整理命名。

### 8.1 文字中可辨认的数据

| 字段 | 转录信息 |
|---|---|
| 所问事项 | 遭仇人诈害，询问事情如何处理 |
| 月支 | 寅 |
| 日支 | 子 |
| 日干、原始起卦时间 | 未明确提供 |
| 世爻 | 子水 |
| 应爻 | 午火 |
| 另一关键爻 | 戌土，发动；讲者称处在中间的爻 |
| 暗动说法 | 讲者称午火被子日冲起而暗动 |
| 卦名、完整六爻、变爻 | 缺失 |

### 8.2 讲者的分析链

1. 世爻子水能克应爻午火，讲者据此认为直接对手不是最主要的问题。
2. 戌土发动克子水，讲者将其解释为中间另有一人造成危害。
3. 寅月木克戌土，讲者称戌土原本受制。
4. 日辰子水冲午火，讲者判午火暗动。
5. 午火生戌土，使戌土得到帮助后作用于世爻子水。

**关系示意，仅复述本例分析：** 子日冲午火 → 午火暗动 → 午火生戌土 → 戌土克世爻子水。

### 8.3 讲者的处置解释与转述反馈

讲者将日辰取象为帮助对方的人，并因日辰与世爻同为子水，推断占问者可以与其沟通。其建议是设法让此人不再帮助对方。

转录称事情在戊寅日或寅日消解；第 27 行给出“戊寅日”，后文多简写为“寅日”。未独立核验原案。

### 8.4 待核验事项

- “世爻戌土”“临月建”等短句与前后反复说明的“世爻子水、临日辰”冲突；表格依照反复一致的数据整理，冲突保留于 Q09。
- 末尾对寅日应期的说明写成“戌土……元神被寅木克制”，指代不清；不能据此恢复完整应期规则。
- 用现实人物停止帮助来解释“日辰不再冲午火”，属于讲者本案取象叙述，不应扩写为人为改变历法或地支关系的规则。
- 午火为什么在本案符合暗动条件，当前资料没有完整展开。

## 9. 案例 C03：父病何时好转

来源：S3，第 29—35 行。案例标题为整理命名。

### 9.1 文字中可辨认的数据

| 字段 | 转录信息 |
|---|---|
| 所问事项 | 父亲病情及何时好转 |
| 卦的描述 | 讲者称为六冲卦，未给出可核对的完整卦名 |
| 日支 | 申 |
| 月支 | 讲者称辰土父母临月建；据此可推为辰月，属于整理推演 |
| 父母爻候选 | 辰土、戌土、未土；三者是否均为本卦爻，缺图待核 |
| 所取用神 | 父母辰土 |
| 忌神 | 寅木；讲者判其受申日冲而暗动 |
| 元神 | 午火，发动，化未土 |
| 完整卦盘及各爻位置 | 缺失 |

### 9.2 取用神

讲者以问父亲取父母爻为用神；面对多个父母爻，在此例中选择临月建、较旺的辰土。

**整理限制：** 这是本例的取用说明，不能单独据此形成“用神多现时永远只取最旺者”的通用规则。

### 9.3 讲者的作用分析

1. 申日冲寅木，讲者判寅木暗动，克用神辰土。
2. 午火为元神，发动后本可生辰土。
3. 讲者以“忌神与元神同动”说明寅木可以先去生午火，再由午火生辰土，并称之为通关等。
4. 但午火化出未土，午未相合；讲者据此认为午火被合住，暂时不能生辰土。
5. 因元神暂不能生用神，寅木仍克辰土，讲者以此解释病情未改善。

### 9.4 应期与转述结果

讲者认为待丑日冲未土，午火不再受合绊，即可生辰土；转录称当事人之父于丑日起床。

这是一则传统占病案例的转述，结果未独立核验。原案日干、完整卦盘和病情背景均不足，不能把它整理成现代医学判断或治疗建议。

### 9.5 本例引入但尚未完整定义的概念

| 概念 | 本例用途 | 尚缺的内容 |
|---|---|---|
| 暗动 | 解释寅木虽非明动仍参与作用 | 暗动与其他日冲状态的完整判别 |
| 忌元同动／通关 | 寅木生午火、午火生辰土 | 成立条件及失败条件 |
| 动化合、合绊 | 解释午火暂时不能生土 | 各类合的区别及适用范围 |
| 冲开合绊 | 解释丑日冲未后作用恢复 | 冲的有效条件与应期优先级 |
| 用神多现 | 在多个父母爻中选择辰土 | 系统取用次序及例外 |

“近病逢冲则愈”在案例开头被提出，而本例恰是在讨论为什么不能只用这句话解释当前状态。本文将其保留为案例背景，不列为无条件判断规则。

## 10. 由本节整理出的分析提纲

**整理归纳：** 下列步骤只是本节内容的组织顺序，不代表完整断卦算法。

1. 明确所问事项和对象，记录时间与卦盘。
2. 按问题选取用神，说明其所在爻位和选择依据。
3. 标出元神、忌神、仇神的五行关系。
4. 检查月建、日辰、本卦动爻和本位变爻的作用范围。
5. 进一步辨认作用者有无力量、是否受到阻碍。
6. 区分关系术语、人物取象、案例结论和事后反馈。
7. 只在资料给出相应条件时讨论应期；缺少条件则保留不确定性。
