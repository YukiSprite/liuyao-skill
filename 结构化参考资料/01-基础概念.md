# 基础概念：阴阳、五行、干支与六亲

来源：[原始基础转录稿](<../六爻零基础 I 增删喂饭级教程，用力讲大白话——建议收藏.txt>)；[原视频](https://www.bilibili.com/video/BV12bzpBuEuG/)。

本文按主题重组第一份转录稿，作为基础概念笔记。整理范围和证据标记见 [资料目录](00-资料目录与整理说明.md)。

## 1. 五行与生克

来源：S1，第 5、7 行。

五行是木、火、土、金、水。讲者先借助日常物质作记忆比喻，再强调：在其术数解释中，五行指向五种性质，不宜始终停留在五种具体物质的理解上。

### 1.1 相生

木生火 → 火生土 → 土生金 → 金生水 → 水生木，首尾循环。

| 生的关系 | 讲者使用的记忆比喻 |
|---|---|
| 木生火 | 木头可以燃烧 |
| 火生土 | 燃烧后的灰烬融入土地 |
| 土生金 | 金属产于山土 |
| 金生水 | 金属熔化后呈液态 |
| 水生木 | 水滋养树木 |

以上是讲者的记忆比喻，不是对自然科学过程的定义。

### 1.2 相克

木克土 → 土克水 → 水克火 → 火克金 → 金克木，首尾循环。

| 克的关系 | 讲者使用的记忆比喻 |
|---|---|
| 木克土 | 树木破土而出 |
| 土克水 | 土可以阻挡水 |
| 水克火 | 水可以灭火 |
| 火克金 | 火可以熔化金属 |
| 金克木 | 金属斧具可以砍木 |

### 1.3 关系速查

**整理推演：** 下表由上述两组关系展开，不是新增规则。

| 参照五行 | 生我 | 我生 | 克我 | 我克 | 同我 |
|---|---|---|---|---|---|
| 木 | 水 | 火 | 金 | 土 | 木 |
| 火 | 木 | 土 | 水 | 金 | 火 |
| 土 | 火 | 金 | 木 | 水 | 土 |
| 金 | 土 | 水 | 火 | 木 | 金 |
| 水 | 金 | 木 | 土 | 火 | 水 |

## 2. 阴阳与爻

来源：S1，第 7、9 行。

### 2.1 爻的表示

| 类型 | 本文示意 | 含义 |
|---|---|---|
| 阳爻 | `━━━━━` | 一条连续横线 |
| 阴爻 | `━━　━━` | 中间断开的横线 |

### 2.2 阴阳需要参照物和比较维度

讲者强调阴阳是相对概念。对同一对象，采用不同的参照物或比较角度，可能得到不同的阴阳定位。

- 以温度比较：50℃ 的水相对于 40℃ 的水为阳，40℃ 的水相对于 50℃ 的水为阴。
- 以体格比较：强壮者相对于瘦弱者为阳，瘦弱者相对于强壮者为阴。
- 改用另一种比较维度，不能直接沿用先前的定位。

本节的操作要点是先说明“与谁比较、比较什么”，再谈阴阳归属。

## 3. 十天干

来源：S1，第 9、11 行。

十天干依次为：甲、乙、丙、丁、戊、己、庚、辛、壬、癸。

| 五行 | 阳干 | 阴干 |
|---|---|---|
| 木 | 甲 | 乙 |
| 火 | 丙 | 丁 |
| 土 | 戊 | 己 |
| 金 | 庚 | 辛 |
| 水 | 壬 | 癸 |

讲者以“五行各分阴阳，五乘二为十”解释此表。

将天干转换为对应五行后，再讨论生克。例如甲乙木生丙丁火，甲乙木克戊己土，庚辛金克甲乙木。

## 4. 十二地支

来源：S1，第 11、13 行。

十二地支依次为：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥。

| 地支 | 五行 | 阴阳 | 生肖 |
|---|---|---|---|
| 子 | 水 | 阳 | 鼠 |
| 丑 | 土 | 阴 | 牛 |
| 寅 | 木 | 阳 | 虎 |
| 卯 | 木 | 阴 | 兔 |
| 辰 | 土 | 阳 | 龙 |
| 巳 | 火 | 阴 | 蛇 |
| 午 | 火 | 阳 | 马 |
| 未 | 土 | 阴 | 羊 |
| 申 | 金 | 阳 | 猴 |
| 酉 | 金 | 阴 | 鸡 |
| 戌 | 土 | 阳 | 狗 |
| 亥 | 水 | 阴 | 猪 |

生肖列按第 11 行依次列举的地支与生肖展开；末尾识别为“构筑”的部分按此处列举语境整理为“狗、猪”。

按五行归类：亥子属水，寅卯属木，巳午属火，申酉属金，辰戌丑未属土。

按阴阳归类：子寅辰午申戌为阳支；丑卯巳未酉亥为阴支。

### 4.1 生克示例

- 子水生寅卯木。
- 寅卯木克辰戌丑未土。
- 戌土克亥子水。
- 午火克申酉金。

**校对说明：** 第 13 行另有“亥水可以克子水”，与本稿自身的五行关系冲突，未收入有效示例。具体见 [Q01](04-校对与待核清单.md#q01-亥水可以克子水)。

### 4.2 本节留下的问题

讲者提出“为什么土对应四个地支，而其他五行各对应两个地支”，但未在本稿中回答。因此本资料不补写其解释。

## 5. 六亲的关系定义

来源：S1，第 13、15 行；排盘时“我”的取法补引 S2，第 29—31 行。

| 与“我”的关系 | 六亲名称 |
|---|---|
| 同我 | 兄弟 |
| 生我 | 父母 |
| 我克 | 妻财 |
| 克我 | 官鬼 |
| 我生 | 子孙 |

基础讲解中的“我”是所选参照五行。具体排六爻六亲时，本教程以**本卦所属卦宫的五行**为参照；不要直接拿占问者的生肖或某一爻的五行替换这个参照。

第二份转录稿用“加上我”解释“五类关系为何称六亲”；这里仅记录为讲者解释。

### 5.1 例一：以土为“我”

来源：S1，第 15 行。

| 五行 | 相对土的关系 | 六亲 |
|---|---|---|
| 木 | 木克土 | 官鬼 |
| 火 | 火生土 | 父母 |
| 土 | 与土相同 | 兄弟 |
| 金 | 土生金 | 子孙 |
| 水 | 土克水 | 妻财 |

### 5.2 例二：以寅木为“我”

来源：S1，第 15 行。

| 示例地支 | 五行关系 | 六亲 |
|---|---|---|
| 辰土 | 木克土 | 妻财 |
| 巳火 | 木生火 | 子孙 |
| 酉金 | 金克木 | 官鬼 |
| 亥水 | 水生木 | 父母 |
| 卯木 | 同为木 | 兄弟 |

这是讲解关系定义的例题，不表示所有卦都以寅木为参照。

## 6. 六亲的广义取象

来源：S1，第 15—19 行。

以下是讲者给出的传统取象示例，尚不是完整的“问题分类—用神选择”规则。人物称谓沿用原讲解的传统语境。

| 六亲 | 讲解中的共同含义 | 原稿示例 |
|---|---|---|
| 父母 | 生养、帮助、保护、庇护 | 父母、长辈、衣服、雨伞、房子 |
| 妻财 | 财物、可使用或支配之物；传统配偶取象 | 钱财、首饰、食物、钥匙、玩具、手机；妻子、女朋友 |
| 官鬼 | 管束、压力、烦恼、令人恐惧之事；传统配偶取象 | 领导、上司、疾病、鬼怪；女占时的丈夫、男朋友 |
| 子孙 | 小辈、养育对象、快乐、解除忧患 | 儿女子孙、宠物、医药、道士、玩乐 |
| 兄弟 | 同辈、竞争、破财、替代性 | 兄弟姐妹、同事、朋友、同学；赌博、借钱；假牙、假肢 |

**整理提示：** 表中为象义范围。同一对象在不同问题里如何取用，本稿没有完整展开，不能仅凭出现某个名词就固定套用六亲。
