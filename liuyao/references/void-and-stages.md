# 旬空、生旺墓绝与辅助术语

本篇按需读取：盘中旬空与主判断有关，或准备使用生旺墓绝、游魂归魂时使用。来源 S4 与 E9—E12 见 [sources.md](sources.md)。这些是解释规则，不是程序新增的自动吉凶字段。

## R12 旬空要结合爻的状态

来源：S4 第 5—13 行；E9《旬空章》；作用条件参照 R06、E6。

旬空是日柱所属十日一旬中未配到的两支。沿用程序的旬空结果，不另凭起卦时支计算。

- 旺相、发动、有日辰或动爻生扶、动而化空、伏藏而旺相等情况，不能仅因空亡就删去该爻的作用。这里的“不空”不等于立即兑现，也不解除回头克等其他制约。
- 有生扶关系时，先核对帮助者能否发挥。元神发动但受回头克，不能只凭“元神动生用”便断空而有救。
- 伏藏、旬空、受克、无援同时出现，可以把具体受阻关系用于综合判断；不把“伏而空”单独定为真空。
- 不采用转录中“有气但不动为空”的残句作为公式。没有足够条件区分真空、假空时，跳过这个标签，照常依据其他有效关系给出主倾向。
- 出空或出月只能作为已有支持可能发挥的条件。须先确认原爻有可用支持、问题期限涵盖该窗口；出空不保证得财，出月不保证月破爻必然转吉。月界沿用排盘的节气月，不直接以公历一号代替。

S4 的远行案例提供了“当前受阻而未来窗口不同”的思路。不得自行编造行程长度、未来反馈或新起卦时间，来替当前的不利关系寻找解除日期。

## R13 生旺墓绝采用五行口径

来源：S4 第 13—19 行；E10《生旺墓绝章》。本技能采用土水同宫，不混用天干阴阳顺逆的另一套长生表。

| 爻五行 | 长生 | 帝旺 | 墓 | 绝 |
|---|---|---|---|---|
| 木 | 亥 | 卯 | 未 | 申 |
| 火 | 寅 | 午 | 戌 | 亥 |
| 金 | 巳 | 酉 | 丑 | 寅 |
| 水 | 申 | 子 | 辰 | 巳 |
| 土 | 申 | 子 | 辰 | 巳 |

先按日月生克、动变关系分析；生旺墓绝只在表项与适用条件都明确时参与，不覆盖主要生克依据。

1. 日辰可以与爻五行对照此表。原爻发动时，才可把其本位变支解释为化长生、化旺、化墓或化绝；静爻在变卦全盘中的排布不构成“化”。
2. 金遇巳：金旺相或有明确日月动爻扶助时，可论长生；休囚无气且火势多时，应论受克，不能看表就一律加一项生扶。
3. 金遇丑：E10 列有未冲动或卦中土多生金时论生、不径论墓的情形。必须说明实际条件，不能把任意丑土都判成困住金。
4. 土遇巳：E10 补充区分休囚无气时论绝，与旺相或得日月动爻生扶时论巳火生土。此项属于外部核验补充，不冒充 S4 已完整讲述。
5. 墓、绝是传统关系术语，不直接对应死亡、疾病诊断或事情必败。遇到未收录的冲合、旺衰优先级冲突，跳过该细项，回到已确定的生克关系。

同一关系不能同时作为两份独立支持计数，例如亥水生木与木长生于亥不是两个互不相关的“加分”。

## R14 术语按上下文解释

来源：S4 第 19—21 行；E11《各门类题头总注》。

| 术语 | 本技能采用的解释 |
|---|---|
| 主象、主事爻 | 当前问题所取用神，不固定是世爻 |
| 身 | 本段古籍语境中指世爻，不另造一个卦身计算步骤 |
| 用神宜旺 | 要综合日月、动爻和动变支持，不只看季节名称 |
| 化吉、化凶 | 对回头生克、化生旺或墓绝空退等关系的概括；仍需逐条核对条件，不由术语直接推出结局 |
| 三墓 | 日墓、动爻墓、动而化墓的分类；不等于世、身、命三种墓。当前仅在已核实作用条件时使用，不额外自动标注动爻墓 |
| 岁君 | 年支；本版未据此新增年度吉凶算法 |
| 岁五、君位 | 涉及第五爻的专门语境；转录和公开文本表述有歧义，不将五爻支一律当成年支 |

“求财看世”的案例不能替代取用规则：求财以妻财为主，财持世时同一爻兼具两种身份。化空按 R12 检查，不因它列在“化凶”术语表里就直接判败；化退仍未收录完整规则。

## R15 游魂归魂只作辅助

来源：S4 第 21—23 行；E12《归魂游魂章》及 E2 八宫序列。

每宫八卦按程序顺序，第七为游魂、第八为归魂。游魂可辅助描述变迁、反复，归魂可辅助描述返回、停留，但以用神及有效生克为主。不能仅凭归魂断出行必不成，也不能凭游魂判断当事人的真实心理。

S4 提到再次占问的古例，也提醒一卦看清就无需再摇。默认完成当前卦分析，不要求反复投币来获取想要的结果。用户主动另占且给出新的六次真实结果时，独立记录新卦，不覆盖旧输入或用反馈重写旧判断。
