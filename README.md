# 六爻 · Liuyao Skill

输入一个问题、六次硬币投掷结果和起卦时间，让 AI 自动排出六爻卦盘，并给出有规则依据的占断。

本项目面向支持 `SKILL.md` 的 AI 助手，已按 Codex 的技能目录结构组织。采用《增删卜易》入门体系，由 Python 程序完成固定排盘，由 AI 结合参考规则完成解读。

教程知识整理、外部补充来源与程序实现分别记录，具体见 [来源与核验记录](liuyao/references/sources.md) 和 [结构化资料目录](结构化参考资料/00-资料目录与整理说明.md)。本项目是独立整理与实现，并非原作者发布的官方工具。

## 可以做什么

- 接收问题、六次投币结果和起卦时间，自动生成本卦、变卦与动爻。
- 用字符画并排展示本卦与变卦，标出阴阳、动爻和世应；静卦只展示本卦。
- 排出卦宫、世应、纳甲、六亲、六神和伏神。
- 计算干支、旬空及日月与各爻的基础关系。
- 围绕所问选择用神，说明主要生扶、克制与动变关系。
- 先给出明确的占断倾向，再解释理由；没有依据的条目不参与判断。
- 按需保存输入、卦盘和分析，方便复盘。

固定排盘可离线执行，无需 API 密钥；自然语言解卦由运行此技能的 AI 助手完成。

## 安装到 Codex

将本项目的 GitHub 链接发给 Codex，请它自动安装即可。

Codex 会根据项目内容完成安装与检查，无需手动复制文件。安装完成后，在新对话中使用 `$liuyao` 调用。

运行需要 Python 3.9 或更高版本；历法依赖已随项目提供，安装时由 Codex 一并处理。

## 使用示例

可以直接对 AI 说：

```text
使用 $liuyao，问这笔款项月底前能不能收回。
起卦时间：2021年10月13日09:14，北京时间。
下面是按第一次到第六次记录的背面朝上数量：
1、1、0、2、1、3。
请先给占断结果，再列出卦象和主要依据。
```

此例会排出 **风泽中孚 → 水天需**，三爻、上爻发动。完整排盘核对信息见 [使用示例](liuyao/references/examples.md)。

### 字符卦图

每次解卦会先展示这样的字符卦图，无需打开图片即可看清六爻形状：

```text
        本卦：风泽中孚         变卦：水天需

上爻    ━━━━━━━━━ ○          → ━━━   ━━━
五爻    ━━━━━━━━━              ━━━━━━━━━
四爻    ━━━   ━━━   世         ━━━   ━━━

三爻    ━━━   ━━━ ×          → ━━━━━━━━━
二爻    ━━━━━━━━━              ━━━━━━━━━
初爻    ━━━━━━━━━   应         ━━━━━━━━━

实线为阳，断线为阴；从下往上对应第 1—6 次投掷。
○ 老阳变阴；× 老阴变阳；箭头标动爻，世／应标在本卦。
```

卦图按上爻到初爻排列，中间空行区分上卦与下卦；使用等宽代码块展示，方便复制分享。详细六亲、六神等信息另列在卦盘表中。

### 如何记录硬币结果

每次同时投掷三枚硬币，共投六次。**第一次对应初爻，位于卦图最下方；第六次对应上爻。** 记录时说明你数的是哪一面。

本项目采用以下背面数约定：

| 背面朝上数量 | 爻值 | 爻象 | 是否变化 |
|---|---|---|---|
| 0 | 6 | 老阴 | 变阳 |
| 1 | 7 | 少阳 | 不变 |
| 2 | 8 | 少阴 | 不变 |
| 3 | 9 | 老阳 | 变阴 |

也接受正面数、六个爻值，或逐次写明三枚硬币的正反面。使用其他约定或从上往下抄卦时，请一并说明。

起卦时间使用实际投币时刻。默认北京时间、零点换日；可以指定其他时区或 23 点换日。时间暂缺时，先根据已有盘面解读，日月等相关项目待补齐后再计算。

## 输出方式

解卦通常包括：

1. **占断结果**：直接回答所问，说明偏能、偏不能或具体的进展倾向。
2. **起卦记录**：问题、投币约定、时间与换日口径。
3. **六爻卦盘**：本卦、变卦，以及从上到下的六爻表。
4. **主要依据**：取用理由及与结论相关的具体爻和规则。

分析采用“先给结果，再讲依据”的表达。生扶与克制交织时，说明判断力度；不把缺少某条进阶规则写成整段无法占断的回复，也不为凑出答案编造规则、概率或现实细节。

这里的结果是传统卦理下的解释性占断；项目目前没有预测准确率的统计验证。

## 单独使用排盘程序

无需调用 AI，也可以生成固定卦盘。在仓库根目录创建 `input.json`：

```json
{
  "question": "这笔款项月底前能不能收回？",
  "tosses": [1, 1, 0, 2, 1, 3],
  "input_mode": "back_count",
  "order": "first_to_sixth",
  "time": {
    "kind": "civil",
    "at": "2021-10-13T09:14:00",
    "timezone": "Asia/Shanghai",
    "day_boundary": "midnight"
  },
  "focus": "妻财"
}
```

运行：

```bash
python3 -B liuyao/scripts/paipan.py --input input.json --output-dir output/example
```

输出目录须为尚不存在的新目录，程序会生成：

- `input.json`：输入记录。
- `chart.json`：结构化排盘结果。
- `chart.md`：含字符卦图的完整卦盘。
- `diagram.txt`：程序生成的纯文本卦图，可单独复制分享。

省略 `--output-dir` 时，直接输出 JSON。程序生成的是排盘底稿；完整自然语言占断由 AI 按技能规则补充。更多参数见 [输入与计算约定](liuyao/references/input.md)。

## 实现与检查

程序处理可重复计算的排盘，AI 负责结合题意作解释。日冲、旬空、月冲等标记与最终吉凶分开处理；变卦完整排布也与原动爻的本位化出区分。

运行排盘检查：

```bash
python3 -B liuyao/scripts/checks.py
```

检查覆盖六十四卦、4,096 种六次投币组合、世应与纳甲一致性、历法边界、输入校验及已核对案例。这些检查验证排盘实现，不衡量预测准确率。

当前参考体系尚未完整覆盖飞伏出入、进退神、三合成局、墓绝、复杂合化及通用应期；解读只采用已有出处且适用条件明确的规则。
